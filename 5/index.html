Part A.2

Recovering Homographies

H maps p to p' = Hp, with the bottom-right entry fixed to 1, leaving 8 unknowns. Each correspondence (x, y) → (x', y') gives two linear equations:

[ x  y  1  0  0  0  -x·x'  -y·x' ] · h = x'
[ 0  0  0  x  y  1  -x·y'  -y·y' ] · h = y'

where h = [a b c d e f g h]ᵀ

Stacking these for all n correspondences gives a 2n×8 system Ah = b, which I solve with least squares since n > 4.

Recovered homography from photo 1 to photo 2 (16 correspondences, with the photos scaled to 756×1008):

[  0.7426   0.0368  188.2371 ]
[ -0.2057   0.8806   52.0788 ]
[ -0.0003  -0.0000    1.0000 ]
Part A.3

Warping the Images

Both warps use inverse warping: the image corners are mapped through H to get the output bounding box, then each output pixel is mapped back through H−1 to find its source location. Pixels whose source falls outside the image get alpha = 0. Nearest neighbor rounds the source location to the closest pixel; bilinear takes a weighted average of the four surrounding pixels.

To rectify, I clicked the four corners of a real-world rectangle and computed the homography that maps them to an axis-aligned rectangle.

Nearest neighbor gives jagged, blocky edges (see the zoomed crops), while bilinear is smoother. Bilinear is slower: about 0.04 s vs. 0.01 s here. I used bilinear for the mosaics.

Part A.4

Blending into a Mosaic

I computed a homography between each pair of neighboring photos and multiplied them together to map every photo into the frame of the middle photo, which stays unwarped. All photos are warped with bilinear interpolation onto one canvas that covers all of their warped corners.

To blend, each photo gets a weight at every pixel equal to that pixel's distance to the photo's edge (a distance transform of its alpha mask), so weights fall to 0 at the edges. I then use a two-band blend: each photo is split into low frequencies (a Gaussian blur) and high frequencies (the photo minus the blur). The low frequencies are combined as a weighted average, which hides seams and exposure differences. The high frequencies are taken from the photo with the largest weight at each pixel, which keeps edges sharp instead of averaging two slightly misaligned copies.
